# Checklist qualite Web/Mobile

## Avant livraison

- Le projet s'installe depuis un clone propre.
- Les commandes de lancement et de build sont documentees.
- Le build passe.
- Le lint ou equivalent passe, si disponible.
- Le parcours principal est teste.
- Les formulaires valident les donnees.
- Les etats vide, chargement, erreur et succes existent.
- L'interface est verifiee sur mobile.
- Les images sont optimisees.
- Les logs inutiles sont retires.

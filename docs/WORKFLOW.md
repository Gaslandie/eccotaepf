# Workflow projet Web/Mobile

## 1. Cadrage

- Objectif unique.
- Public cible.
- Perimetre inclus et exclu.
- Criteres d'acceptation.

## 2. Conception

- Parcours principal.
- Etats vide, chargement, erreur, succes.
- Donnees manipulees.
- Contraintes mobile/desktop.

## 3. Implementation

- Changement limite au besoin.
- Architecture locale respectee.
- Pas de secret dans le code.
- Pas de refonte non demandee.

## 4. Verification

- Commandes lancees notees.
- Scenarios testes notes.
- Echecs documentes.

## 5. Livraison

- Recette client.
- Version livree.
- Rollback ou correction rapide identifie.
- Retours classes par priorite.

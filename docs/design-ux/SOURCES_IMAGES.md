## Logo

Le logo d'ECCOTA-EPF **ne se prend pas sur Internet**. Tant que le logo officiel n'est pas
fourni par le client, le site utilise un logotype typographique provisoire produit pour ce
projet, en SVG, décrit dans `CONTENUS_PROVISOIRES.md`.

## À la livraison

Les images provisoires sont remplacées par les photos réelles d'ECCOTA-EPF. Les lignes
correspondantes de ce tableau sont mises à jour, pas supprimées : savoir ce qui a été utilisé
et quand fait partie du dossier du projet.

# Audit UI/UX

## Lisibilite

- Les titres expliquent clairement la page.
- Les boutons utilisent des verbes d'action.
- Les textes longs ne debordent pas sur mobile.
- Les elements importants restent visibles sans chercher.

## Navigation

- L'utilisateur sait ou il est.
- Il peut revenir ou annuler quand c'est necessaire.
- Les liens et boutons importants sont distincts.

- Chargement :
- Vide :
- Erreur :
- Succes :
- Hors ligne, si applicable :

## Qualite visuelle

- Couleurs coherentes avec la marque.
- Espacements constants.
- Images nettes et optimisees.
- Pas d'elements decoratifs qui genent la comprehension.
